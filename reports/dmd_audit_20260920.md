# DMD audit, 2026-09-20

## Observed failure

The stopped endpoint experiment has 110 recorded updates. Prompt0000 is a
recognizable red car at step0, nearly uniform yellow at step25, and pink at
step100. Thus the collapse happened during fine-tuning, not during loading or
preview decoding. Loss peaks include step23=944, step56=1817, step66=8294.
These surrogate losses do not measure sample quality or KL directly.

## Implementation findings

1. The advertised standard endpoint DMD was actually using an unnormalized
   RF score-gradient surrogate: `(1-t)^2/t * (v_real-v_fake)` at s=0.
   Its sign is consistent with score matching, but its time weighting differs
   from the normalized x0-DMD in Bidirectional's `_student_dmd_step`.
2. At s=0 the phased fake loss was `min(1,10*t^2)*MSE(v,epsilon-x0)`.
   At t=0.001 its weight is 1e-5 while the generator score coefficient is
   approximately 998. This heavily emphasizes the least-supervised fake
   predictions. This is a plausible collapse mechanism; causality and quality
   improvement still require the new run, not merely finite scalar losses.
3. The endpoint config used fake:G=1:1, despite the prior requested 5:1.
   This increases the risk of the fake score lagging behind a changing student.
4. Endpoint tests had not established correctness: one asserted +4 for an
   integrated constant velocity over decreasing time [1,0], whose answer is -1;
   the other failed to initialize the mode attribute used by the code.
5. Four-step full-rollout BPTT is intentional in endpoint mode. Tiny actual
   Wan tests show identical outputs and parameter gradients with block
   checkpointing on/off. No checkpoint coefficient mutation bug was found in
   this path (the projection itself is outside checkpointed blocks).

## Corrections

Added `boundary` normalization. In final endpoint mode:

```
x0_real = xt - t*v_real
x0_fake = xt - t*v_fake
direction = (x0_fake-x0_real) / clamp(mean(abs(xs-x0_real)), 1e-5)
loss = 0.5 * mean((xs-stopgrad(xs-direction))**2)
```

This matches Bidirectional's normalized direction after converting its
TrigFlow denoiser outputs to the RF convention used here. Reduction remains
latent mean and the 0.5 factor is explicit; Bidirectional uses a scaled latent
sum, so numeric loss/LR scales should not be compared directly.

The fake final-endpoint loss is now ordinary unweighted RF velocity MSE.
The standard endpoint config uses score times [0.02,0.98], fake:G=5:1,
G LR=2e-5, fake LR=1e-5, save every5. Original phase-mode score/DSM formulas
remain available: their conditional re-noising and derivative signs passed
analytic tests. Boundary mode also supports same-endpoint Euler projection
for phase experiments, but existing phased configs are not silently changed.

Added endpoint RMS and score-time diagnostics. Reject mismatched phase fake
heads and unsupported nonzero trajectory weight in final mode. Resume guards
now include score-time bounds. No collapsed DMD checkpoint is reused.
